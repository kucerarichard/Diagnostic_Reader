# Canonical Specimen Store

These specimen files were extracted from the user-supplied `specimens.txt` upload. The source/edition was not identified in that upload, so the files are frozen transcriptions as supplied, not edition-verified scholarly texts. SHA-256 values in `catalog.json` identify the exact bytes used. Do not silently replace or normalize these texts; if a verified edition is selected later, create a new specimen revision and update every relevant manifest.

R9 is intentionally not populated: the upload contains no scan image. R9 requires a scan specimen and must not receive the full poem transcription.
